# Developer leads — small HTML5 game developers

~105 developers who make small, self-contained HTML5 games, researched
for the free featured-placement offer in `OUTREACH_EMAIL.md`.

**Read this first — what "contact" means here.** Not one of these people
publishes an email address on the profile I could verify. That is the norm,
not a gap in the research: GitHub hides the profile email field by default,
and itch.io deliberately does not require developers to be contactable at
all. So every row below gives a **contact route** — a public page where the
person chose to be reachable — and never an email address. **No email in
this file was guessed, inferred, or constructed from a name**, and none
should be. If a row says `github.com/handle`, the way in is that profile's
own links or an issue on the game's repo, per the GitHub-issue variant in
`OUTREACH_EMAIL.md`.

**Research limits, stated plainly.** This session's network policy blocks
itch.io, js13kgames.com, Google Play, Newgrounds, GameJolt, Reddit, and
every social network — only GitHub and web search were reachable. So this
list is built from GitHub, and it is therefore biased toward developers who
publish source. That is a lucky bias for you: source-publishing developers
are the ones who can actually hand over a single self-contained HTML file.
But it means **itch.io is completely unmined** and is your biggest
remaining seam — see "Sources still to mine" at the bottom.

**Why js13kGames dominates this list.** Entrants ship a complete game in
**13,312 bytes zipped**. Your spec asks for under 2MB. They are already two
orders of magnitude inside your hard limit, in a single file, with no
external requests, usually with touch support — the closest thing to a
drop-in match that exists anywhere. The 2026 jam (theme: Unicorns and
Rainbows) **closes 13 September 2026**; send the week after.

Legend — **Fit**: ⭐⭐⭐ = mobile/touch or one-button, near drop-in ·
⭐⭐ = small and self-contained, may need touch work · ⭐ = desktop-first,
WebXR, or multiplayer (needs network — will not work in your sandbox
as-is).

## Sources still to mine (blocked from this session)

Open these yourself — they are where the rest of the list is:

1. **itch.io HTML5 tag, sorted by newest** — thousands of small devs, most
   with comments open. Completely unmined here. Your single biggest seam.
2. **js13kgames.com/2025/games and /2026/games** — the full 197-entry lists
   with per-entry author links, including the eight finalists above whose
   handles I couldn't confirm.
3. **Ludum Dare / GMTK / Global Game Jam web builds** — same shape as js13k,
   larger files.
4. **Newgrounds and GameJolt HTML5 sections.**
5. **Google Play** — search "HTML5 games", "web games offline"; small
   publishers wrapping web games in a WebView already understand your model.
6. **The one-html-page-challenge submissions** (via @Metroxe above).

**Aggregators — a different play.** GameDistribution, GamePix, SOFTGAMES,
GameFlare, MarketJS and Playgama each sit on thousands of HTML5 games and
existing developer relationships. One conversation could beat a hundred
individual emails. But their games are built around *their* SDKs and ad
calls, which means external network requests — the exact thing your sandbox
forbids. Worth one exploratory email each; don't build the plan on it.

## Realistic expectations

Cold outreach to individual developers converts in the low single-digit
percents. From ~105 leads, personalized properly and sent at the right
time, plan on **3–8 yes replies** — and note that the two Tier A bulk leads
alone could outweigh all of them for catalog depth.

Order of work, if you only do part of it:

1. **Tier A** — 8 emails, potentially 130+ games.
2. **Tier C** — finished games, no deadline, warmest audience.
3. **Tier B** — but not before 14 September 2026.
4. Everything else, as time allows.
